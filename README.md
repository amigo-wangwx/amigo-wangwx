# 王伟旭

Android / Kotlin / Compose Multiplatform 开发者。

我主要关注移动端工程效率、调试工具、网络排查、自动化流程，以及能真正减少重复劳动的小工具。

## 重点项目

| 项目 | 说明 | 技术方向 |
| --- | --- | --- |
| [Debug Toolkit](https://github.com/amigo-wangwx/debug-toolkit) | Android 调试工具包，包含调试面板、网络拦截、配置切换和 Gradle 插件，面向 debug 构建使用。 | Kotlin / Android / Gradle Plugin |
| [Curl Visualizer](https://github.com/amigo-wangwx/curl-visualizer) | 基于 Compose Desktop 的 curl 请求可视化调试工具，支持响应体搜索、JSON 格式化、请求历史和批量 URL 检测。 | Kotlin / Compose Desktop / CLI |
| [Bookmarks KMP](https://github.com/amigo-wangwx/bookmarks-kmp) | Chrome 书签审阅、链接检测、整理和导出工具，支持从 HTML/CSV 加载并生成可重新导入 Chrome 的书签文件。 | Kotlin Multiplatform / Compose Desktop |
| [kmpact](https://github.com/amigo-wangwx/kmpact) | 面向 Android 开发者的 Compose Multiplatform 工具集成平台，将常用命令行能力包装成图形化工作台。 | Kotlin Multiplatform / Compose Multiplatform |
| [FrenziedProguard](https://github.com/amigo-wangwx/FrenziedProguard) | Android 混淆字典和混淆规则生成工具，用于实验与研究 ProGuard 混淆效果。 | Java / Android / ProGuard |

## 工作方向

- Android 调试工具与工程效率建设
- Kotlin、Compose Desktop、Compose Multiplatform
- 网络请求排查、Deep Link、包体和命令行工具
- 将重复操作沉淀成可复用、可验证、可交付的工具
